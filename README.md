## This method achieves high-precision molecular fingerprint prediction through the bimodal fusion of fragmentation trees and MS/MS features

### 1.TreeLSTMChild :
#### This is a TreeLSTM (Tree-Structured Long Short-Term Memory) model implemented based on PyTorch, designed to learn vector representations of nodes and entire trees from tree-structured data.

### 2.compute_loss :
#### Calculate two commonly used loss functions in contrastive learning: ContrastiveLoss and SupConLoss.

### 3.eval_model :
#### A PyTorch implementation that includes CNN, FNN, GCN, and SVM, designed for feature learning and prediction on sequential data, vector data, and graph-structured data.
